# Design and Analysis of Algorithms (DAA) Practicals 🚀

A comprehensive Python implementation of core computer science algorithms covered in the **Design and Analysis of Algorithms (DAA)** practical curriculum.

## 📋 Experiments Overview

| File | Topic / Algorithm | Paradigm / Category | Time Complexity |
| :--- | :--- | :--- | :--- |
| [`exp1.py`](exp1.py) | **Interpolation Search & Binary Search** | Searching & Analysis | $O(\log \log n)$ avg / $O(\log n)$ |
| [`exp2.py`](exp2.py) | **String Matching (Naive & KMP)** | Pattern Matching | $O(n + m)$ (KMP) |
| [`exp3.py`](exp3.py) | **Minimum Spanning Tree (Kruskal's & Prim's)** | Greedy Algorithms | $O(E \log V)$ |
| [`exp4.py`](exp4.py) | **Shortest Path (Dijkstra's Algorithm)** | Graph Algorithms | $O((V + E) \log V)$ |
| [`exp5.py`](exp5.py) | **Min-Max Finding** | Divide and Conquer | $O(n)$ |
| [`exp6.py`](exp6.py) | **Matrix Chain Multiplication** | Dynamic Programming | $O(n^3)$ |
| [`exp7.py`](exp7.py) | **N-Queens Problem** | Backtracking | $O(N!)$ |

---

## 🛠️ Requirements & Setup

No external dependencies are required. All scripts use standard Python libraries (`time`, `random`, `heapq`, `sys`).

### Running an experiment:
```bash
python exp1.py
```
